## Note on a test-infrastructure gap found during T6 (fixed same-day)

`tests/conftest.py`'s `client`/`real_client` fixtures used `base_url="http://test"`. This story is the first to chain a `Secure`-flagged cookie (the refresh cookie, set by `/login`) into a second request within the same test — httpx's cookie jar silently refuses to resend a `Secure` cookie over a plain-`http` base URL, even through `ASGITransport`, which never does real TLS. No prior test ever needed this (login's own tests only ever inspected `Set-Cookie` once, never replayed it). Fixed by changing both fixtures' `base_url` to `"https://test"` — `ASGITransport` is fully in-process and does no real network/TLS negotiation, so the scheme change has no effect beyond satisfying httpx's cookie-jar policy. Full suite (182 tests) reverified green after the fix.

## Note on the security baseline's fourth case

Every other story's traceability matrix in this project lists "revoked-session token → 401" as one of four uniform security-baseline cases per `AGENTS.md` §5. This story is the one place that invariant is *intentionally* not uniform across its own two endpoints (resolved OD-2) — so instead of one baseline row, the matrix lists both outcomes explicitly (`/logout` → 204 leniency, `/logout-all` → 401 standard) to make the deliberate asymmetry traceable rather than looking like an oversight.
