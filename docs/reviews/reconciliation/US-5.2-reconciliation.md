## Summary

All 10 spec ACs (PS-AC1–PS-AC7, XC-AC1–XC-AC3) have a traceability-matrix row. ## Spec Drift / Reconciled Deviations

None of the following are unreconciled drift — the shipped code matches the **approved spec** (v2) in every case. They are named per the skill's Completion Criteria so they are not silently absorbed into the PASS verdict.

- **[Reconciled, not drift] `If-Match: *` on unknown ETag (PS-AC2 / OD-1).** `hooks/useProfileUpdate.ts` (lines ~3–32) always sends `If-Match` — the cached ETag when known, else the literal `"*"` — rather than PS-AC2's literal "sent only when an ETag is known ... omitted otherwise" wording. This is not silent implementation drift: spec v2 FR-2 and the spec's own PS-AC2 Traceability Matrix row *state this exact behavior as the requirement*, citing OD-1's human resolution at `HUMAN_SPEC_APPROVAL`. The shipped code matches the approved spec; the divergence is spec-vs-story-AC-literal-wording, already resolved and recorded in three places (open-decisions v2, spec v2, ac-test-matrix). `implementation-verifier` and `security-reviewer` independently reached the same non-blocking conclusion. No further action needed.
- **[Reconciled, Minor, non-blocking] `ProfileScreen.tsx` imports `SUPPORTED_LOCALES`/types directly from `api/types.ts`.** Confirmed at `frontend/src/screens/ProfileScreen.tsx:14`. Flagged Minor/non-blocking by both `implementation-verifier` and `security-reviewer` as an AGENTS.md §3 layering nit with no functional or security effect. Not spec drift (no AC governs internal import structure).
- **[Reconciled, additive] `LoginScreen.tsx` modified beyond the implementation plan's literal Files-To-Modify list.** Confirmed at `frontend/src/screens/LoginScreen.tsx` — reads `location.state.message` and renders it in a `<p role="status">`. This is required by FR-7/PS-AC7 ("lands on `/login` with a confirmation message") and is named directly in `task_breakdown` T10's own verification bullet, not an undocumented scope expansion. All 7 pre-existing `LoginScreen.test.tsx` assertions confirmed still passing per `docs/evidence/US-5.2-implementation-report.md`.
