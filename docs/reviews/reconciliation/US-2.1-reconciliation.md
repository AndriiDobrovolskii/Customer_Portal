# Reconciliation Report: US-2.1 Login

**Story ID:** US-2.1 (spec's own field; backlog story is US-2.1)
**Reviewed:** 2026-08-31
**Overall Verdict:** Pass (one gap found and fixed during this review, not carried forward)

## Summary

Every AC in scope — this story's own LI-AC1–LI-AC6, plus DA-AC6/DA-AC7/DA-AC8 (owned by this story per resolved OD-10) — has a traceability-matrix row, an existing test function, and that test asserts the AC's actual stated behavior (status, body shape, and persisted state, not just a status code). One gap was found during this review: `docs/tests/US-2.1-ac-test-matrix.md` referenced `test_dummy_verify_password_comparable_cost_to_real_verification` in `tests/unit/core/test_security.py`, but the function had never actually been written. Writing it surfaced a real (currently harmless, since its return value is discarded by the only caller) logic bug in `verify_password_dummy()` — it hashed and verified the *same* dummy value, so it always returned `True` instead of behaving like a genuine non-match. Both the missing test and the underlying bug were fixed in this session, verified against a clean gate re-run (167/167 tests, mypy/lint-imports/ruff/secrets all green), before finalizing this verdict as Pass rather than carrying the gap forward.

## Spec Drift

- **[Low, disclosed] Refresh-token cookie `Path` differs from the source story's literal text.** Story/spec state `Path=/v1/auth`; the shipped cookie uses `Path=/api/v1/auth` (`app/modules/users/router.py`, `login` handler). This is not undisclosed drift — `docs/designs/api/US-2.1-api-design.md`'s "Reactivation branch" note and a code comment both explain the correction: the app's actual deployed routes all live under `/api/v1/...` (per `app/api/v1/router.py`'s prefix), and a cookie scoped to `/v1/auth` would never actually be sent back to the real `/api/v1/auth/refresh` endpoint once US-2.3 builds it — the story's own path convention doesn't include the `/api` prefix anywhere, matching the same divergence `US-1.4-api-design.md` already accepted for its own contract. Recorded here per this skill's own mandate to surface every divergence, even a correct and disclosed one.

## Verdict Rationale

Pass: every AC in scope has a matrix row, an existing test, and that test asserts the AC's actual behavior — including the one gap this review itself found (a missing test function and the real bug it would have caught) — fixed in-session and re-verified against a clean gate (167/167 tests) rather than left open. The one Spec Drift item is Low severity and was already disclosed in the design docs, not discovered here for the first time.
