# Task Breakdown — US-2.3 (spec ID US-007)

Unlike US-2.2, this story has a request-body-free but response-body-bearing endpoint (`200` + `RefreshResponse`), so a `schema-builder` task exists (US-2.2 had none). No `T0`-style unowned-infra task is needed for `app/core/cache_keys.py` — that helper is within `data-layer-builder`'s own stated remit ("a documented key-prefix helper" for a `cache.py` gateway), unlike US-2.2's `hash_refresh_token()` extraction, which landed in `app/core/security.py` (outside any module) during its service task. `app/core/email.py`'s new `EmailSender` method is the one true unowned-infra touch this story has — it's core infra used only by the service, so it's folded into T4 rather than given its own task, per the pattern the module's own execution skills already accommodate for cross-cutting `core/*` additions.
