## Notes

- T1/T2/T2b run in parallel — none depends on another, per the standard rule.
- **T6 (OD-15) resolved 2026-09-02 (user):** `service-and-router-builder` builds `scripts/verify_audit_chain.py`, the closest-fit execution skill despite its stated contract not literally covering standalone scripts.
- **Partition safety net (OD-16) resolved 2026-09-02 (user):** T3b's migration also creates a `DEFAULT` partition, preventing the hard `INSERT` failure `planner`'s Risks section flagged. No separate maintenance-job task added to this breakdown.
- T3/T3b/T3c are three separate migration-manager tasks, not one, because (a) T3 must complete and commit before T3b can create the freed `audit_log` name (a hard sequencing dependency within the same execution skill), and (b) T3c is fully independent of both — it touches four unrelated, already-shipped tables and could run before, after, or interleaved with T3/T3b without consequence. Bundling all three into one migration file would violate `AGENTS.md` §4's own guidance that a `CONCURRENTLY` index needs its own migration inside `autocommit_block()`.
- See OD-16 above for the partition-maintenance resolution — no separate task needed.
- **Hash-chain genesis rule (OD-17, resolved 2026-09-02):** first-ever row seeds `previous_hash` from a fixed sentinel; each subsequent day's first row seeds from the most recent non-empty prior partition's final `row_hash` (skipping empty days). T3b's trigger SQL can now be finalized against this rule — see db-design.md's `audit_log` section for the exact seed query.
- **AU-AC9 retention job (OD-18, resolved 2026-09-02):** explicitly out of scope for this task breakdown. No task builds a retention/cold-storage job — it's blocked on OD-9 (legal/DPO sign-off on the cold-storage target), which remains open. AU-AC9 stays `[manual]`, undelivered by US-3.3.
- Carried-forward, non-blocking Open Decisions (OD-3, OD-4, OD-6–OD-10) are not separate tasks — each is either already reflected in T2/T3b's design (OD-3's NULL-padded view mapping, OD-4's four-of-five-table scope) or remains a documented gap in the relevant file's code comments (T2/T4), matching this project's established pattern for non-blocking findings.
